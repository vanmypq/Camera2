# Camera Lớp Học (com.vanmypq.cameralophoc)
Camera chạy nền (Foreground Service + CameraX), chụp bằng chạm đúp/chạm 3 lần vào màn hình (cửa sổ overlay 1px nhận ACTION_OUTSIDE), hoặc nút trong thông báo. Chọn camera trước/sau. Ảnh lưu Pictures/CameraLopHoc.
Build: mở thư mục bằng Android Studio (Sync) -> Build > Build APK, hoặc đẩy lên GitHub để Actions tạo APK (tab Actions > Artifacts).
